# OpenClaw Hao123 Portal

# 中俄台跨境套利 AI OS

这是一个面向中俄台跨境项目的 AI 操作系统雏形。

核心目标：

- AI 自动发现套利机会
- AI 自动分析利润
- AI 自动生成招商 H5
- AI 自动生成视频脚本
- AI 自动生成图片 Prompt
- AI 自动生成中俄双语内容
- AI 自动生成平台发布素材

---

# 快速启动

## 1. 安装环境

需要 Node.js 18+。

## 2. 一键生成全部内容

```bash
npm run build
```

该命令会自动运行：

- 套利分析
- Content Package
- Video Package
- Image Package
- H5 页面生成

---

# 常用命令

```bash
npm run arbitrage
npm run content
npm run video
npm run h5
npm run build
```
