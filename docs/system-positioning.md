# 中俄台跨境套利 AI OS 定位

## 这不是普通网站

这个系统的目标不是：

- 单纯卖货
- 单纯导航站
- 单纯招商页

而是：

> AI 自动发现套利机会 + 自动招商 + 自动分析 的跨境 AI OS。

---

# 核心定位

## 第一层：数据

长期建立：

- 中俄价格数据库
- 商品数据库
- EAC 风险数据库
- 平台规则数据库
- Prompt 数据库

---

# 第二层：AI 分析

自动完成：

- 利润分析
- 风险分析
- GO / NO GO
- 招商潜力分析
- AI 放大能力分析

---

# 第三层：AI 自动化

自动生成：

- H5

- 微信文案
- 小红书文案
- Telegram 文案
- 俄语文案

# 第四层：AI 自动招商
