# AI 图片生成系统

## 当前目标

把每一个跨境项目自动转化为：

- 小红书封面
- 微信长图
- Telegram 横版图
- 项目卡片
- 招商海报

---

# 当前运行方式

执行：

```bash
node scripts/image-prompt-generator.js
```

自动生成：

```text
/data/image-packages.json
```

---

# 当前已经支持

## 1. 小红书封面

规格：

- 1080x1440

适合：

- 小红书
- 微信封面

# 2. 微信长图

规格：

- 1080x3000

适合：

- 招商长图

# 3. Telegram / YouTube 横版图

规格：

- 1280x720

# 4. 项目卡片

规格：

- 1080x1080

适合：

- 朋友圈
- 项目展示
