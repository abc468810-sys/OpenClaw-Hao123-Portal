# 3. 视频 API

计划接入：

- Sora
- Seedance
- Runway

# 4. 汇率 API

计划接入：

- 实时 RUB/CNY
- 实时 USDT/CNY

- 实时利润分析
- 实时排行榜

---

# 5. 数据来源

仅考虑：

- 官方 API
- 人工录入
- 合规公开数据

不采集：

- 非公开数据
- 用户隐私数据
- 受限访问内容
