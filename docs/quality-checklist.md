# AI OS 质量检查清单

## 页面检查

- 首页是否可打开
- Dashboard 是否正常
- H5 页面库是否正常
- 页面链接是否失效
- 手机端是否正常显示

---

# 数据检查

- 项目数据库 JSON 是否有效
- 图片包是否生成
- 视频包是否生成
- Content Package 是否生成
- H5 页面是否生成

---

# 内容检查

- 是否存在夸大收益
- 是否存在虚假承诺
- 是否存在敏感违规内容
- 风险提醒是否存在
- 中俄双语是否合理

---

# 构建检查

执行：

```bash
npm run build
```

确认：

- 是否报错
- generated-h5 是否生成
- JSON 是否生成
- GitHub Actions 是否通过

---

# GitHub Pages 检查

- 首页是否可访问
- Dashboard 是否可访问
- H5 页面库是否可访问
- CSS 是否加载正常
- 手机打开是否正常

---

真实数据质量。
