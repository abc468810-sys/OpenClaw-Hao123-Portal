# AI OS 一键构建系统

## 当前目标

通过一条命令：

自动生成：

- 套利分析
- Content Package
- Video Package
- H5 页面

---

# 当前运行方式

执行：

```bash
node scripts/build-all.js
```

---

# 当前自动执行内容

## 1. 套利分析

运行：

```bash
node scripts/arbitrage-calculator.js
```

生成：

- 利润分析
- GO / NO GO
- 排名

---

## 2. Content Package

运行：

```bash
node scripts/content-package-generator.js
```

生成：

- H5 内容
- 平台发布素材
- 俄语版本

---

## 3. Video Package

运行：

```bash
node scripts/video-script-generator.js
```

生成：

- 视频脚本
- 分镜头
- Prompt

---

## 4. H5 页面

运行：

```bash
node scripts/h5-page-generator.js
```

生成：

- HTML 页面
- 手机 H5
- 招商页
