# MVP 路线图

## 目标

把当前系统拆成三个阶段：

- MVP 可用版
- 增强版
- 商业化版

避免功能扩散，优先形成可展示、可测试、可持续迭代的产品。

---

# 第一阶段：MVP 可用版

## 目标

形成一个可上线、可展示、可手动运营的 AI OS。

## 必须完成

- 首页
- Dashboard
- 项目排行榜
- 招商 H5 页面库
- 项目数据库
- 一键构建
- GitHub Pages 上线

## 判断标准

用户打开网站后，能看懂：

- 这是做什么的
- 有哪些项目
- 每个项目为什么值得看
- 如何生成 H5
- 如何生成视频脚本

---

# 第二阶段：增强版

## 目标

让系统具备自动内容生产能力。

## 必须完成

- 自动生成 Content Package
- 自动生成 Video Package
- 自动生成 Image Package
- 自动生成中俄双语内容
- 自动生成项目报告
- 自动生成招商 H5

## 判断标准

输入一个项目后，系统可以生成：

- H5
- 视频脚本
- 图片 Prompt
- 平台发布素材
- 俄语版本

---

# 第三阶段：商业化版

## 目标

形成可服务客户、招商、收集线索的系统。

## 必须完成

- 后台数据录入
- 客户线索表
- 报价单生成
- 项目报告导出
- 真实图片生成
- 真实视频生成
- GitHub Pages 或独立域名部署

## 判断标准

系统能支持：

- 给客户看
- 给代理看
- 给合作方看
- 用于招商演示
- 用于项目筛选

---

# 当前优先级

## 最高优先级

1. GitHub Pages 上线
2. Dashboard 稳定
3. H5 页面库稳定
4. 数据结构稳定
5. 内容质量检查

## 暂缓

- 自动发布
- 大规模采集
- 用户系统
- 复杂后台

---

# 原则

先上线，再完善。

先手动运营，再自动化。

先数据准确，再扩大规模。
