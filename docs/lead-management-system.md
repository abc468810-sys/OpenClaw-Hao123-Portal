# 招商线索管理系统

## 当前目标

建立一个简单、可扩展的招商线索结构。

当前阶段：

- JSON 数据
- 手动录入
- 手动跟进

后续可接：

- Airtable
- Supabase
- Notion
- CRM

---

# 当前字段

## 基础信息

- 来源平台
- 意向项目
- 客户类型
- 国家/城市
- 联系方式

---

# 商业信息

- 预算区间
- 意向等级
- 跟进状态
- 备注

---

# 当前目标

不是复杂 CRM。

而是：

- 判断哪些项目更容易转化
- 判断哪个平台效果更好
- 判断哪些内容更有效
- 建立招商数据反馈
