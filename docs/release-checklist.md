# AI OS 发布检查清单

## 上线前必须检查

### 页面

- 首页是否正常
- Dashboard 是否正常
- H5 页面库是否正常
- 手机端是否正常
- CSS 是否正常

---

# 数据

- projects.json 是否有效
- 图片包是否生成
- 视频包是否生成
- Content Package 是否生成

---

# 内容

- 是否存在错别字
- 是否存在夸大收益
- 是否存在敏感内容
- 风险提醒是否存在
- 中俄双语是否合理
