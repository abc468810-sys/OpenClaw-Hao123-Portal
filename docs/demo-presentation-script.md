# Demo V1 演示话术

## 一句话介绍

这是一个面向中俄台跨境项目的 AI 招商系统 Demo。

它不是单纯网页，而是把：

- 项目筛选
- AI 内容生成
- 招商 H5
- 视频脚本
- 图片素材
- 线索收集
- 数据反馈

串成一个闭环。

---

# 演示顺序

## 第一步：打开首页

说明：

这里是系统总入口。

可以看到：

- Demo V1
- 项目排行榜
- H5 页面库
- 招商线索 Dashboard

---

# 第二步：打开 Demo V1

说明：

这是俄罗斯蜂蜜项目的示范版本。

它展示的是：

- 一个跨境资源项目如何被 AI 包装
- 如何形成 H5
- 如何形成视频脚本
- 如何形成招商报价结构
- 如何引导客户留下线索

---

# 第三步：讲项目逻辑

俄罗斯蜂蜜不是单纯卖货。

真正的模式是：

俄罗斯资源
↓
中国市场包装
↓
AI 内容放大
↓
私域/小红书/Telegram 测试
↓
招商合作

---

# 第四步：讲视频模块

当前视频还是占位。

但系统已经能生成：

- 30 秒短视频脚本
- 60 秒招商视频脚本
- 分镜头
- 字幕
- 视频生成 Prompt

后续可以接：

- Sora
- Seedance
- 可灵
- Runway

---

# 第五步：讲报价结构

当前报价是示范占位。

未来可以变成：

- 基础合作包
- 区域代理包
- 深度招商包

用于不同客户层级。

---

# 第六步：讲线索表单

当前是静态表单。

后续可以接：

- Airtable
- Supabase
- Notion
- GitHub Issues

形成线索数据库。

---

# 第七步：打开 Dashboard

说明：

Dashboard 用来展示：

- 项目评分
- 项目排行榜
- 套利案例
- GO / NO GO

---

# 第八步：打开 Leads Dashboard

说明：

这里用来查看：

- 线索来源
- 意向项目
- 客户类型
- 预算区间
- 跟进状态

---

# 结尾话术

这个 Demo 的价值不是某一个页面。

真正价值是：

> 项目发现 → AI 包装 → 内容生产 → 招商展示 → 线索反馈 → 数据优化

形成一个可以不断扩展的跨境招商操作系统。
