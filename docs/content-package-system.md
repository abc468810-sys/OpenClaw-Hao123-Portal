# Content Package 系统

## 什么是 Content Package

每一个跨境项目都会自动生成一个：

> Content Package（内容包）

内容包用于：

- H5
- 视频
- 小红书
- Telegram
- VK
- 招商页
- 中俄双语内容

---

# 当前生成方式

运行：

```bash
node scripts/content-package-generator.js
```

自动输出：

```text
/data/content-packages.json
```
