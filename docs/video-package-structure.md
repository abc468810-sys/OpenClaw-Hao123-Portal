# 视频包（Video Package）结构

## 什么是 Video Package

每一个跨境项目：

- 泥炭土
- 蜂蜜
- 琥珀
- 工业备件
- 二手车

都可以自动生成一个：

> Video Package

即：

- 视频标题
- 视频脚本
- 分镜头
- 字幕
- Prompt
- 封面标题
- AI 视频生成参数

---

# 当前已经支持

通过：

```bash
node scripts/video-script-generator.js
```

自动生成：

```text
/data/video-packages.json
```

---

# Video Package 内容

## 1. 视频标题

适合：

- 微信
- 小红书
- Telegram
- 视频号

---

# 2. 30 秒视频脚本

结构：

- 强钩子
- 痛点
- 机会
- 商业模式
- 行动号召

---

# 3. 60 秒招商视频脚本

适合：

- 招商
- 项目介绍
- Telegram
- YouTube

---

# 4. 分镜头

包含：

- 画面
- 旁白
- 屏幕文字
- Prompt

---

# 5. 视频 Prompt

当前已经支持：

- Sora
- Seedance
- CapCut

后续支持：

- 可灵
- 即梦
- Runway
