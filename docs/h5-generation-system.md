# H5 自动生成系统

## 当前目标

输入项目数据库后：

自动生成：

- HTML 页面
- 手机全屏 H5
- 微信长图风格页面
- 招商展示页

---

# 当前运行方式

执行：

```bash
node scripts/h5-page-generator.js
```

自动输出：

```text
generated-h5/
```
